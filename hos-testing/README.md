# HOS Testing - Fleet Drive Safety
simple python program calculating driving hours

## Files
- `driving_hours.py` - Calculates driving durations
- `run.txt` - Contains the input driving intervals
- `output.txt` - Generated results after running the program

## Supported Formats
- 12-hour time: 2pm-5am, 9:30AM-11:00PM
- 24-hour time: 14:00-17:00
- Supports spaces and mixed capitalization.
- Handles overnight intervals and invalid inputs.

## How to Run
1. Install Python 3.
2. Open a terminal in this folder.
3. Run: python driving_hours.py

4. Check `output.txt` for the results.

No external libraries are required.
